The Job Portal Dashboard is an interactive analytics tool built in Tableau Cloud to visualize and interpret recruitment data efficiently. It consolidates multiple dimensions — such as Company, Country, Qualifications, Preferences, Experience, Salary Range, Skills, and Work Type — into a single, unified view.
